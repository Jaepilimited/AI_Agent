메일 발송

스프레드시트의 수신자 목록과 Docs 템플릿으로 한 사람씩 메일을 보냅니다. 점검 · 미리보기 · 나에게 테스트를 거친 뒤 전체 발송합니다.

사용 방법 · 시트 양식 · 첨부

순서

  1. 구글 연결 — 처음 한 번. 구글 화면에서 모든 항목에 체크하고 허용하세요.
  2. 스프레드시트 · 시트 · 보내는 주소를 고릅니다. 「시트 열기」로 그 시트를 바로 열 수 있습니다.
  3. 점검 — 보낼 대상과 문제를 행마다 보여 줍니다. 오류가 하나라도 있으면 「전체 발송」이 잠깁니다.
  4. 행 오른쪽 미리보기 · 나에게 테스트로 실제 모양을 확인합니다 (테스트는 내 메일함으로만 갑니다).
  5. 전체 발송 — 확인 창의 인원·제목을 보고 누릅니다. 진행 중 「중지」 할 수 있고, 보낸 행은 시트 G열에 O, A열에 날짜가 적힙니다.

시트 양식 (기존 메일 툴과 같음)

  • 열 위치가 정해져 있습니다: A 날짜 · B 템플릿 탭 이름 · D 이메일 · G 전송여부 · H 비고. 1행은 헤더, 2행부터 수신자.
  • B열은 Docs 템플릿 탭 제목과 똑같이 적습니다.
  • 1행 헤더가 {name} · {value1} 처럼 중괄호면, 그 열 값이 템플릿의 같은 변수 자리에 들어갑니다. 템플릿에 있는 변수가 시트에 없으면 오류로 막습니다.
  • G열이 O 인 행은 이미 보낸 것으로 보고 건너뜁니다.

첨부

  • 공통 첨부: 아래에서 파일을 고르면 이번 발송의 모든 수신자(테스트 포함)에게 붙습니다. 합계 15MB · 10개까지.
  • 수신자별 첨부: 시트 1행 I열 이후에 첨부 열을 만들고 행마다 Drive 링크를 적습니다 (여러 개는 줄바꿈·쉼표). 구글 문서·시트·슬라이드는 PDF 로 붙고, 내 계정에서 열 수 있는 파일이어야 합니다.
  • 메일 한 통은 이미지·첨부 합쳐 24MB 를 넘을 수 없습니다 — 넘으면 점검에서 막습니다.

알아두기

  • Docs 템플릿을 고치거나 탭을 새로 만들면 반영까지 최대 10분 걸립니다 (점검에 "10분 뒤 다시" 로 보입니다).
  • 행 사이 2.5초 간격으로 보냅니다 (100명 ≈ 4분). 하루 2,000통까지.
  • 페이지를 닫아도 발송은 서버에서 계속됩니다 — 다시 열면 진행 상황이 보입니다.
  • 같은 시트를 기존 Apps Script 와 동시에 돌리지 마세요.
  • "발송 여부 불확실" 행은 Gmail 보낸편지함에서 확인하고, 나간 행은 G열에 O 를 적은 뒤 「확인했음」을 누르세요.

보낼 목록

  • 공용 주소가 없으면 Gmail 설정 → 계정 → '다른 주소에서 메일 보내기' 에 등록하세요. 한 시트는 한 툴로만 보내세요 (기존 Apps Script 와 동시에 돌리지 마세요).
  • 수신자별 첨부는 시트의 '첨부' 열(Drive 링크)로 — 자세한 건 위 「사용 방법」.
