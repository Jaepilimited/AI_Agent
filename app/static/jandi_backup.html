잔디 백업 도우미

잔디에 쌓인 내 대화와 첨부파일을 내 PC 폴더에 그대로 저장합니다. 각자 자기 PC 에서, 자기 잔디 계정으로 실행합니다. 저장된 폴더의 index.html 을 열면 인터넷 없이도 방별 대화를 검색하며 볼 수 있습니다.

잔디 백업
북마크를 준비하는 중입니다…

이 버튼은 누르는 버튼이 아닙니다. 마우스로 북마크바에 끌어다 놓으세요. 북마크바가 안 보이면 Ctrl + Shift + B 를 누르세요.

사용 순서

  1. 위의 잔디 백업 버튼을 북마크바로 끌어다 놓습니다. (한 번만 하면 됩니다)
  2. Chrome 또는 Edge 에서 잔디 웹(https://팀이름.jandi.com/app)에 로그인하고, 대화 목록이 보이면 북마크바의 잔디 백업을 누릅니다.
  3. 오른쪽 위에 뜬 패널에서 받을 범위(토픽 · 1:1 · 그룹 대화 · 첨부파일 포함)를 고르고 저장 폴더 선택 후 시작을 누릅니다. 바탕화면 등에 빈 폴더를 하나 만들어 고르고, 브라우저가 묻는 저장 권한을 허용합니다.
  4. 끝나면 고른 폴더 안 잔디백업_팀이름_날짜 폴더의 index.html 을 엽니다. 중간에 멈췄다면 같은 폴더를 골라 다시 시작하세요 — 끝난 방은 건너뛰고 이어서 받습니다.

들어가는 것

  • 이 계정이 볼 수 있는 대화: 참여 중인 토픽(공개·비공개), 1:1 대화, 그룹 대화
  • 메시지 · 댓글 · 스티커 · 투표 · 시스템 기록(초대·나감·공지 등)
  • 첨부파일과 스티커 이미지 (선택) — 크기를 확인하고, 50MB 이하는 SHA-256 도 기록합니다
  • 방마다 대화 뷰어(HTML) · 엑셀용 CSV · 텍스트 · 원본 JSON

들어가지 않는 것

  • 참여하지 않은 토픽, 이 계정이 볼 수 없는 대화
  • 이미 삭제된 메시지 · 파일, 수정 전 내용(편집 이력)
  • 잔디가 열람을 제한한 오래된 기록
  • 잔디로 되돌리는 복원 — 백업은 열람용 보관본입니다

개인정보

대화와 파일은 잔디에서 브라우저로, 브라우저에서 내 PC 폴더로 곧장 저장됩니다. 셀라 서버는 이 내용을 받지도, 보지도 않습니다. 북마크 안에 프로그램 전체가 들어 있어서 실행하는 동안 셀라에 접속하지도 않습니다.

알아 둘 것

  • PC 의 Chrome 또는 Edge 가 필요합니다. 폴더에 직접 저장하는 기능을 다른 브라우저는 지원하지 않습니다.
  • 첨부파일을 포함하면 수십 GB · 몇 시간이 걸릴 수 있습니다. 디스크 여유를 확인하고, 끝날 때까지 잔디 탭을 닫거나 PC 를 절전 상태로 두지 마세요. 패널에서 일시정지 · 중지할 수 있습니다.
  • 이 도구는 잔디 웹 화면의 내부 구조를 이용합니다. 잔디가 업데이트되면 멈출 수 있습니다. 그럴 땐 이 페이지에서 버튼을 다시 끌어다 놓아 최신 북마크로 바꾸고, 그래도 안 되면 셀라 담당자에게 알려 주세요.
