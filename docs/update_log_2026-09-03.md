## 변경 사항

### 1. [기능] COA·MSDS 파인더 — 롯트번호를 붙여넣으면 문서를 모아 준다 (08-31, 09-03)
- 전용 페이지 `/coa-finder` + 사이드바 진입. **COA 는 롯트번호로, MSDS 는 제품명으로** 구글 드라이브에서 찾는다
- 사람이 실제로 붙여넣는 모양(엑셀 복사·줄바꿈 섞인 목록)을 그대로 받는다. 헤더 낱말로 열을 찾고, 열이 없으면 추측하지 않는다
- 진행률은 SSE 로 흘리고 결과는 ZIP 으로 내려받는다 — **못 받은 파일은 목록으로 남긴다**(반쪽 ZIP 이 평범한 ZIP 처럼 내려오던 것)
- 판정은 네 갈래다: 정확 · 접미 붙음 · **경계 없는 부분일치 = 확인필요** · 없음. 넓히지 않는다는 것을 회귀로 못 박았다
- ⛔ **드라이브 토큰이 죽으면 "전부 없음" 으로 보인다** — 조회 전에 생존 검사를 하고, 만료와 미연결을 구분해 말한다
- 09-03: COA·MSDS 를 폴더와 버튼으로 가르고, **COA 가 없는 롯트 목록**을 따로 뽑는다 (섞이면 사람이 파일명을 읽어 골라야 했다)

### 2. [기능] 비밀번호 복구 — 경로가 둘이고, 둘 다 있어야 한다 (08-31, 09-01)
- **구글 본인 확인** (가입자 66명 중 **64명·97%**) — 구글이 서명으로 신원을 보증하므로 본인이 직접 새 비밀번호를 정한다
- **관리자 요청** (나머지 2명) — ⛔ 이 경로는 계정을 아무것도 바꾸지 않는다. 부서·이름은 신원 증거가 아니다
- ⛔ 처음엔 `users.email` 만 봤는데 **활성 AD 436명 중 238명이 이메일 공백**이라 절반이 영영 못 쓸 뻔했다 → `mail` 이 비면 `userPrincipalName` 을 쓰고, 회사 도메인이면 **로컬파트**로 잇는다 (AD 436명 로컬파트 충돌 0건 실측)
- 관리자 임시 발급은 다음 로그인에 강제 변경. 본인이 정한 비밀번호는 강제하지 않고 서 있던 강제는 내린다
- ⛔ 커버리지 수치를 dev DB 로 재고 있었다 — 프로덕션(10.1.200.5)과 **다른 데이터**여서 실측치로 교체했다

### 3. [성능] 로그인 실패에 **136초** 걸리던 것 (08-31)
- 팀을 잘못 고른 사람이 "사용자를 찾을 수 없습니다" 한 줄을 보려고 2분 16초를 기다렸다
- 원인은 AD 가 느린 것이 아니라 **WAS 에서 LDAP 이 방화벽으로 막혀 있는데 로그인 경로가 그 조회를 기다린 것**이었다
- 자가 복구를 백그라운드로 던지고 즉시 답한다 → **136초 → 0.1초**. 못 찾은 이유("다른 팀 소속이 아닌지 확인해 주세요")도 함께 말한다

### 4. [기능] Entra ID(OIDC) 로그인 — 설정만 넣으면 켜지는 상태로 준비 (09-02)
- 지금은 비밀번호를 셀라가 자체 저장하고 CRM 도 따로 저장한다. 로그인 단계부터 통합하려는 준비다
- **지금은 꺼져 있다.** 설정 4개가 비면 버튼도 안 보이고, IT 가 `.env` 에 값을 넣는 날 **코드 배포 없이** 켜진다
- ⛔ 선결 조건은 **HTTPS** — Entra 회신 URL 은 https 여야 해서 현재 `http://10.1.100.5` 로는 등록 자체가 안 된다. 보내기 전에 막고 이유를 말한다
- 신원은 이메일이 아니라 **불변 객체 ID(`oid`)** 로 잇는다. 첫 로그인이 계정을 만들지는 않는다

### 5. [기능] 저장한 질문 · 첫 화면 개인화 (08-27)
- 답변 옆에서 **질문을 정기 실행으로 저장**하면 아침 브리핑에 결과가 함께 실린다
- **`내가 자주 묻는 것`** — 질문 이력으로 첫 화면 칩을 개인화한다
- 제안 칩을 **자기 팀 담당 국가**로 좁힌다 (매출·광고 각각)
- 대화에 사용자 원문을 함께 남겨 **지난 대화에서도 `@@` 지정이 살아 있게** 했다

### 6. [기능] 고친 실패를 자산으로 굳힌다 (08-27)
- 조직이 검증한 **질문↔SQL 짝**을 모아 프롬프트 예시로 준다
- 고친 붐따(👎)를 **골든 문항 후보**로 올린다 — 같은 실패가 두 번 나가지 않게

### 7. [기능] 잔디 브리핑을 사람마다 다르게 (09-01)
- **받을 시각**을 08:00~18:30 중에서 본인이 고른다 (릴레이 회차와 같은 목록이어야 한다 — 없는 시각을 저장하면 브리핑이 영영 안 온다)
- **받을 항목**을 절 단위로 끈다. ⛔ 켠 것이 아니라 **끈 것을 저장한다** — 켠 목록이면 나중에 절이 늘 때 기존 사용자에게 영영 안 보인다
- 끈 것은 "잔디로 안 받는다" 이지 "안 본다" 가 아니다. 첫 화면 문서와 알림함에는 그대로 남는다
- **참조(CC)로만 온 메일은 할 일에서 뺀다** — 섞이면 진짜 내 일이 뒤로 밀린다 (메일 목록에서는 빼지 않는다)

### 8. [버그] 막으려던 관문이 요청을 죽이고 있었다 — 8건 사망 (08-27)
- ⛔ **미래 날짜 상한 관문**: 규칙은 이미 "미래 날짜를 포함한다" 로 뒤집혔는데 **강제하던 코드가 그대로 남아** 이틀간 반대 규칙 두 벌이 돌았다. 판정부터 깨져 있어 상한이 있는데도 없다고 읽었다 — 14일 발동 10회 중 **9회가 오탐**, 요청 **5건 사망**
- ⛔ **기간별 순위 관문**: 3건을 죽였는데 죽은 3건이 **전부 잘릴 수가 없는 SQL** 이었다. 이제 실제로 잘릴 때만 막는다
- 둘 다 **막지 않고 공시하는** 쪽으로 바꿨다. 재발 감시를 골든셋에 못 박았다
- ⛔ **"성공 0회" 라고 쓴 것은 셀 수 없는 값이었다** — 성공 로그는 INFO 라 프로덕션에서 통째로 버려진다. 거부당한 SQL 원문을 직접 읽어 실측치로 정정했다

### 11. [성능] 캐시 번호를 손으로 세지 않는다 — 776KB → 0바이트 (08-31)

- 방향을 뒤집어 **내용 해시를 자동으로 붙이고 진짜 캐시를 켰다** → 두 번째 페이지 로드 **776KB → 0바이트**
- ⛔ 가장 나쁜 실패는 "영영 낡은 파일에 갇히는 것" 이라 `immutable` 은 지금 파일의 지문과 일치할 때만 준다

### 12. [기능] 조직 정보를 관문으로 — 검색으로 새지 않게 (09-02)

- **권역명(`서구권`·`동남아`)으로 물으면 되묻는다** — 팀 이름이 아니라 관문을 못 넘는데, 흘려보내면 무관한 노션 문서가 나온다. 되묻되 후보를 담당 국가까지 붙여서 준다
