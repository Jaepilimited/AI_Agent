# IT 요청 — AI Craver 알림 발송 경로 개방

작성 2026-08-20 · 담당 임재필(데이터분석팀) · **1순위: SMTP / 2순위: 잔디**

---

## 배경 한 줄

사내 AI 서비스(AI Craver)가 **알림을 서버 밖으로 내보낼 수 없습니다.** 앱 화면 안에서는
알림이 뜨지만, 메일·잔디로는 한 통도 나가지 않습니다. 9월 전사 사용 시작에 앞서
경로 하나가 필요합니다.

---

## 요청 1 (1순위) — 사내 SMTP 릴레이 개방

### 무엇을

| 항목 | 내용 |
|---|---|
| 출발지 | **10.1.150.5 (WAS, 앱 서버)** — 필요 시 10.1.150.105(배치)도 함께 |
| 목적지 | 사내 메일 릴레이 서버 **:587 (STARTTLS)** — 25 도 가능 |
| 방식 | 아웃바운드 TCP 허용 (HTTP 프록시로는 불가 — 아래 참조) |
| 발신 계정 | `no-reply@cravercorp.com` 같은 **시스템 발신 주소 1개** |

### 알려주셔야 할 것

1. 릴레이 호스트 주소·포트
2. 인증 방식 — 무인증 사내 릴레이인지, 계정/비밀번호가 필요한지
3. 허용 발신 주소 (새로 만들지 / 기존 계정을 쓸지)
4. **외부 도메인 수신 허용 여부** — AD 계정에 `umma.io`·`b2link.co.kr` 등 외부 도메인이
   섞여 있어, 사내 도메인만 허용이면 그분들에게는 메일이 가지 않습니다

### 현재 상태 (실측 2026-08-19)

```
WAS 10.1.150.5 / APP 10.1.150.105 양쪽 동일
  smtp.gmail.com:587 · :465        → 즉시 차단
  smtp.office365.com:587           → 즉시 차단
  mail.skin1004korea.com:25 · :587 → 타임아웃
  localhost:25 (로컬 MTA)          → 미설치
DNS 는 정상 해석됨 — SMTP 포트만 막혀 있습니다.
```

⚠️ 서버는 `HTTPS_PROXY=http://10.1.50.2:3128` 로만 외부에 나갑니다. **HTTP 프록시는
SMTP 를 중계하지 못하므로**, 프록시 화이트리스트 추가로는 해결되지 않고 방화벽에서
직접 열어야 합니다.

### 용도

- 보고서를 공유했을 때 **지목된 직원에게** 안내
- 사용자가 남긴 오류 제보(👎)의 **처리 결과 회신**
- 데이터 이상징후·시스템 점검 실패 통보

발송량은 하루 수십 통 수준이며, 본문에 고객 데이터는 담기지 않습니다
(제목·링크·처리 메모만).

### 개방 후 검증

```bash
python3 -c "import smtplib,ssl; s=smtplib.SMTP('<호스트>',587,timeout=10); \
s.starttls(context=ssl.create_default_context()); print(s.noop())"
```

앱 쪽은 **설정 네 줄만 넣으면 켜집니다** (코드 배포 불필요):

```
MAIL_ENABLED=true
SMTP_HOST=<호스트>
SMTP_PORT=587
SMTP_FROM=no-reply@cravercorp.com
```

## 요청 2 (2순위) — 프록시 화이트리스트에 잔디 추가

| 항목 | 내용 |
|---|---|
| 출발지 | 10.1.150.5 (WAS), 10.1.150.105 (APP) |
| 경유 프록시 | **10.1.50.2:3128** |
| 추가 도메인 | **`wh.jandi.com`** (HTTPS/443, 아웃바운드 POST) |

### 현재 상태 (실측)

```
프록시 경유
  wh.jandi.com:443                      → 000 (CONNECT 차단)
  generativelanguage.googleapis.com:443 → 404 (통과 — 허용 도메인이라 서버까지 도달)
```

같은 프록시로 허용 도메인은 정상 통과하므로 **네트워크가 아니라 화이트리스트 문제**입니다.

### 용도 — 팀 공용 채널 알림만

자가 점검 실패·골든셋 품질 하락·매출 이상징후를 **팀 채널**에 올립니다.

⚠️ 잔디 인커밍 웹훅은 **채널 전용**이라 개인에게 보낼 수 없습니다. 그래서 개인 알림
(보고서 공유·제보 회신)은 **메일이 본체**이고 잔디는 보조입니다.
개인 발송이 꼭 필요하면 잔디 워크스페이스에 봇/API 설치가 별도로 필요합니다.

### 개방 후 검증

```bash
curl -x http://10.1.50.2:3128 -X POST -H 'Content-Type: application/json' \
  -d '{"body":"연결 테스트"}' https://wh.jandi.com/connect-api/webhook/<발급URL>   # → 200
```

## 요약

| | 요청 | 없으면 |
|---|---|---|
| 1 | 방화벽: WAS → 메일 릴레이 587 + 발신 계정 1개 | 개인 알림이 앱 안에만 머무릅니다 |
| 2 | 프록시 화이트리스트: `wh.jandi.com` | 장애·이상징후를 사람이 화면에 들어가야만 압니다 |

두 건 모두 **사람 수와 무관한 1회 설정**입니다. 수신자는 사내 AD 주소를 그대로 쓰며,
직원이 늘어도 추가 요청이 필요 없습니다.
