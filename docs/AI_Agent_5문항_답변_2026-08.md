## ④ 범용 AI (ChatGPT·Gemini) 대비 차별점과 대체 가능 영역

**차별점 — 모델이 아니라 연결이다**

| | 우리 AI Agent | ChatGPT/Gemini |
|---|---|---|
| 사내 매출 데이터 (BigQuery) | ✅ 실시간 조회 | ❌ 접근 불가 |
| 사내 문서 (노션·CS·전성분) | ✅ | ❌ |
| 사내 언어 ("센앰"·"델메"·"포마") | ✅ 용어사전 + 오타 보정 | ❌ |
| 권한별 데이터 접근 (손익 등) | ✅ 서버 강제 | ❌ 개념 없음 |
| 숫자 정합성 보증 | ✅ Daily Metrics 와 동일 산식 검증 | ❌ |
| 개인 캘린더·메일 | ✅ 개인 OAuth | 제한적 |

**대체 가능 영역 (인정할 것)**: 일반 지식·번역·초안 작성은 범용 AI 가 더 낫다. 우리 Agent 의 존재 이유는 "회사 데이터에 연결된 질문"이며, 범용 영역까지 이기려는 시도는 하지 않는다.

## ⑤ 신뢰할 수 있는 서비스 — 권한·정합성

- **용어·정의 통일**: 브랜드 4종(스킨천사·우마·좀비뷰티·커먼랩스) 정의 확정, 대륙·수량·신제품 규칙 문서화 — 답이 사람·시점에 따라 달라지지 않게.
- **모르는 것을 아는 척하지 않음**: 전성분 미보유 SKU 는 "미상"으로 분리(커버리지 89.7%를 답변에 명시), 성분 미포함 질문의 오답 구조 제거.
