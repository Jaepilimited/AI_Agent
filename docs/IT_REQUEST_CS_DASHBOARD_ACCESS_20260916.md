# 셀라 → CS 대시보드 집계 API 접근 허용 요청

2026-09-16 점검 결과, 사용자 PC에서는 CS 대시보드가 정상 응답하지만 셀라 운영 WAS에서는 회사 프록시가 HTTP 403 `ERR_ACCESS_DENIED`를 반환합니다. 직접 연결도 시간 초과됩니다. 셀라가 대시보드와 동일한 집계로 답하도록 아래 읽기 전용 연결이 필요합니다.

- 출발지: WAS `10.1.150.5`의 `ai-craver` 서비스
- 기존 프록시: `http://10.1.50.2:3128`
- 목적지: `http://34.64.99.254:8061`
- 메서드·경로: `GET /api/dashboard/summary`, `GET /api/overseas/dashboard/summary`
- 쿼리: 조회 기간(`startDate`, `endDate`), 채널·유형·상태·범위 필터
- 필요 없는 권한: 새로고침 POST, 데이터 수정, 관리 기능

앱은 주소를 고정하고 리다이렉트를 따르지 않으며 응답에서 집계값만 사용합니다. 원본 고객·이메일·주문 내역을 답변·로그·캐시에 남기지 않습니다. 접근 실패 시 같은 조건의 대시보드 링크를 제공하며 다른 자료를 대시보드 수치로 대체하지 않습니다.

허용 후 WAS의 앱 환경(서비스 .env 및 기존 프록시)을 사용해 두 GET 경로의 HTTP 200과 응답 `source` 값(`google_sheets`, `google_sheets_overseas`)을 확인하면 됩니다. 네트워크 허용 후 앱 코드 재수정 없이 실시간 집계 답변이 동작합니다.

이 문서는 요청 초안이며 IT팀으로 발송하지 않았습니다.
