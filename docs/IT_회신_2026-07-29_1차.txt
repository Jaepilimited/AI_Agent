■ 1. DB 계정 접속 불가 [최우선]

WAS에서 DB 3306 TCP 연결은 정상이나 계정 로그인이
거부됩니다.

 오류: Access denied for user 'ai'@'10.1.150.5'
       (using password: YES)

방화벽은 정상이므로 계정 권한 문제로 보입니다.
'ai' 계정이 아래 두 출발지에서 접속 가능하도록
권한 부여를 부탁드립니다.

 · WAS 10.1.150.5
 · APP 10.1.150.105

비밀번호가 변경되었다면 함께 알려주시면 감사하겠습니다.
현재 애플리케이션은 기동되었으나 DB 연결만 실패하는
상태라, 이 건만 해결되면 기능 검증에 들어갈 수 있습니다.


■ 2. Proxy 3128 접근 불가

"TCP 3128 접근 가능"으로 회신 주셨으나, WAS·APP·Web
3대 모두에서 10.1.50.5:3128 연결이 되지 않습니다.

서버 구축은 위 방식으로 우회했으나, 서비스 운영에는
외부 API 호출이 필수라 이 경로가 반드시 필요합니다.

■ NTP 서버 주소

3대 모두 현재 시각은 정확하나 NTP 동기화 서비스가
비활성 상태입니다. 사내 NTP 서버를 찾기 위해
172.16.1.13과 10.1.50.5로 테스트했으나 응답이
없었습니다.

장기 운영 시 시각이 어긋나면 외부 API의 TLS 인증서
검증이나 로그인 토큰 만료 판정에 문제가 생길 수
있습니다. 사내 NTP 서버 주소를 알려주시면 저희가
직접 설정하겠습니다.
(없다면 현 상태로 운영하며 주기적으로 확인하겠습니다)
