### 1. [기능] 알림 — 사이드바에 알림함 (2026-08-19)

  ⛔ 기존 회신은 **메모가 달린 것만** 돌려줘서 "내가 신고한 게 접수는 됐나"를 알 수 없었다 —
  그 침묵이 8월 회신 0건의 배경이었다

  로컬 MTA 없음, 프록시는 HTTP 전용이라 릴레이 불가, Google OAuth 스코프는 `gmail.readonly`.
  IT 가 열어주면 **같은 문구를** 메일로도 보낸다 — API 모양은 그대로 뒀다
