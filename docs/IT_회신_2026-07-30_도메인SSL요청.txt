현재 IP 기반 HTTP로 임시 운영하며 검증을 진행했습니다.
정식 서비스 전환을 위해 아래를 요청드립니다.

▸ 사내 도메인 등록
 · 대상 서버 : Web 10.1.100.5
 · 희망 도메인 : IT팀 사내 표준에 맞춰 지정 부탁드립니다.
   (참고로 현재 운영 중인 서비스는 사용자들이
    172.16.1.250:3000 으로 직접 접속하고 있어,
    이번 이관을 계기로 도메인 접속으로 전환하려 합니다)

▸ SSL 인증서 발급
 · 위 도메인에 대한 사내 인증서 발급 부탁드립니다.
 · 인증서와 키 파일을 전달해 주시면 저희가 Web
   서버에 적용하겠습니다.
   (또는 IT팀에서 직접 배치해 주셔도 됩니다)

▸ 방화벽 추가

 · 목적지 : Web 10.1.100.5
 · 포트   : TCP 443
 · HTTPS 전환 후 80은 443 리다이렉트 용도로만
   사용할 예정입니다.

3. 협의 필요 — 서비스 전환 일정
━━━━━━━━━━━━━

도메인·SSL이 준비되면 아래 순서로 전환하려 합니다.
일정 협의가 필요한 부분이 있어 미리 공유드립니다.

 1) HTTPS 적용 및 최종 검증
 2) 데이터 최종 동기화 (짧은 점검 시간 필요)
 3) 사용자 공지 후 접속 주소 전환
 4) 기존 서버(172.16.1.250)는 롤백 대비로 1주일 유지

전환 시점은 업무 영향이 적은 시간대로 협의하고자
합니다. IT팀에서 선호하시는 시간대가 있으면
알려주시면 맞추겠습니다.
