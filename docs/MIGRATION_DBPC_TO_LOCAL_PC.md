## 4. 이관 순서

1. 새 PC 에서 `scripts/migration_probe_local_pc.ps1` 실행 → IP·DHCP·BLOCKED 목록 확정
2. 보안팀 요청 (2절, BLOCKED 만) → 허용 후 프로브 재실행해 전부 OK 확인
3. 새 PC 준비: Python 3.11 · Node · pm2 · MariaDB 11.7 설치, `python_bcj` 복사, `sshenv` 재생성, `~/.ssh` 키 2개(`crm_onprem`·`gcp_skin1004`) 이동
4. MariaDB `skin1004_ai` 덤프 → 새 PC 복원 (CRM 을 잠깐 멈추고 뜬다)
5. 서비스를 새 PC 에서 기동하고 **사내 다른 PC 에서** 각 포트 접속 확인 (프로브는 들어오는 쪽을 못 잰다)
6. 예약 작업 이관 — **DB_PC 쪽을 먼저 끄고** 새 PC 쪽을 켠다 (잔디 이중 발송 방지)
7. `track.skin1004.app` 포워딩 전환 (보안팀과 시각 맞춤) → 외부에서 수신 거부 링크 직접 눌러 확인
8. 1~2주 병행 후 DB_PC 반납

## 5. 반납 전에 결정할 것

- **AI Craver 롤백 수단이 사라진다.** 지금 롤백은 "172.16.1.250 의 `.env` 에서 리다이렉트 한 줄 지우고 재기동" 이다. 이관 후 2.5개월 무사고였으니 롤백 대비를 끝낼지, 새 PC 에 같은 껍데기를 둘지 정한다
- **옛 주소 172.16.1.250:3000 북마크가 죽는다.** 껍데기를 새 PC 로 옮겨도 주소가 달라 같은 효과는 없다
- `CRM/skin1004-crm` 의 git remote URL 에 **GitHub 토큰이 평문으로** 들어 있다. 폴더째 옮기면 같이 간다 — 이참에 자격증명 관리자로 옮기고 토큰을 교체하는 것을 권한다
