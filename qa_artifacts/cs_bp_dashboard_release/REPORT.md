# CS → BP 통합 및 CS 대시보드 연결 — 2026-09-16

## 운영 반영

- 기존 CS 문서 소스를 BP로 통합했다. 등록 목록에 BP 한 항목만 나타나며 기존 `@@CS`, `@@cs문서`, `@@notion_cs`는 BP의 호환 별칭이다.
- BP는 제품 Q&A 시트, `team=CS`로 제한한 Notion 검색, 제품정보를 한 번의 답변 합성에 사용한다. 실제 Q&A 시트와 CS 문서 루트 및 검색된 페이지의 원본 링크를 붙인다. QA 로딩 실패나 검색 결과 없음 때문에 독립된 CS 문서 근거를 버리지 않는다.
- 데이터소스 선택·상태·@@ 자동완성에서 원본 링크를 제공한다. BP 원본 링크 두 개는 좁은 상태 행 아래에서 줄바꿈된다.
- 기존 브라우저의 CS 선택값과 이미 본 소스 대장을 함께 BP로 이관하여 사용자가 꺼 둔 소스를 다시 켜지 않는다. 국내·해외 CS 및 고객지원 그룹 링크는 사용자가 지정한 `http://34.64.99.254:8061/`이다.
- 국내/해외 CS의 지원 가능한 질문은 대시보드의 읽기 전용 GET API를 우선 사용한다. 요약, 일별·사유별·상태별·유형별, 국내 채널별·대표상품별 건수를 표·차트와 함께 출력하며 링크에 같은 기간·필터를 넣는다.
- 지원하지 않는 조건(국가·고유 주문·통화 환산·그룹별 금액 등)은 기존 상세 조회로 넘기고 자료 기준을 밝힌다. 대시보드 접근 실패는 다른 자료의 수치로 대체하지 않고 같은 조회 조건의 원본 링크로 안내한다.

## 현재 외부 차단 조건

**운영 서버에서 대시보드 집계를 직접 읽는 기능은 프록시 허용 전까지 제한된다.** WAS의 기존 Squid 경로는 HTTP 403 `ERR_ACCESS_DENIED`, 직접 연결은 시간 초과다. 사용자 PC에서는 실제 API와 화면이 정상 응답한다. 네트워크 정책을 변경하거나 우회하지 않았다.

- 허용 대상: WAS `10.1.150.5` → 기존 프록시 `10.1.50.2:3128` → `34.64.99.254:8061`
- 읽기 경로: `/api/dashboard/summary`, `/api/overseas/dashboard/summary`
- IT 전달 초안: `docs/IT_REQUEST_CS_DASHBOARD_ACCESS_20260916.md` (발송하지 않음)
- 허용 후 코드 재수정 없이 실제 집계·차트 답변 경로가 동작한다.

해외 CS 대시보드의 원본은 `google_sheets_overseas`이며 Shopify 환불 테이블과 별도다. 실제 대조한 2026년 8월 수치는 대시보드 68건·USD 5,828.60, Shopify 94건·USD 7,015.31이다. 이 검증 값을 답변에 하드코딩하지 않았다. 국내 대시보드는 같은 기간 51건·보상 기록액 1,060,500원이었다.
